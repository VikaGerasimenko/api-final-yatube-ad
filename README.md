# Yatube API

API для социальной сети Yatube. Проект позволяет создавать посты, оставлять комментарии, подписываться на авторов и получать ленту постов.

## Возможности

- Аутентификация по JWT токенам
- Создание, редактирование, удаление постов
- Комментирование постов
- Подписка на авторов
- Поиск по подпискам
- Пагинация ответов API

## Технологии

- Django 3.2
- Django REST Framework 3.12
- Simple JWT
- SQLite3
